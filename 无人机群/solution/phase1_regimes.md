# Phase 1：远离临界——三种噪声下的不同命运

## 目标

固定密度 `rho = 4`（`N=400, L=10`），只改噪声 `eta`，看一个 Vicsek 集群在三种 regime 下完全不同的"性格"：齐整但僵硬 / 活跃但有共识 / 嘈杂且无序。

## 实验设计

| 名称 | `eta` | 预期 |
| --- | --- | --- |
| 低噪声 | 1.5 | 集群很快锁成一坨，`<phi>` 接近 0.9 |
| 中等   | 3.0 | 接近相变区，`phi` 涨落明显 |
| 高噪声 | 4.5 | `<phi>` 仅 ~0.1，集群完全无序 |

每种跑 600 步、warmup 150 步。

## 关键观察

典型输出：

```
[phase1] low noise (eta=1.5):    <phi>=0.885   Var(phi)=0.0001
[phase1] medium (eta=3.0):       <phi>=0.580   Var(phi)=0.0021
[phase1] high noise (eta=4.5):   <phi>=0.112   Var(phi)=0.0026
```

注意两件事：

1. `<phi>` 跨越**一个数量级**：从 0.88 到 0.11；
2. **方差最大的是中等噪声**：低噪声集群锁死了 → 几乎没涨落；高噪声虽然散漫但每一步都接近 0；中等噪声经常徘徊于 0.4–0.7 之间，方差最大。这是相变附近"巨涨落"的典型签名。

## 产出图

- `phase1_phi_timeseries.svg`：三条 `phi(t)` 平滑曲线，颜色区分。
- `phase1_swarm_eta***.svg`：三张 quiver 快照——低噪声是单色阵列，中等是色块拼接，高噪声是彩色斑点。
- `phase1_steady_phi.svg` / `phase1_phi_variance.svg`：稳态均值与方差柱状图。

## 为什么这一阶段重要

- 给读者一个**直观的相变锚点**：序参量并非"略变"，而是命运分岔。
- 中等噪声下涨落最大暗示了**相变指纹**——下一阶段就用涨落峰值精确定位 `eta_c`。
- 同时埋伏笔：你以为低噪声"齐整"是好的？阶段三会给你看，它的另一面是"听不进新指令"。
