# Phase 1：远离临界——三种密度的不同命运

## 目标

在静态森林（`mode="static"`）上做一个直观对比：用同样的中心点火、同样的 `L=80`，只改密度 `p`，看火灾大小如何**跨越三个数量级**。这是后续两阶段（精确定位渗流相变、自组织到临界）的体感先导。

## 实验设计

三个 regime：

| 名称 | 密度 | 预期 |
| --- | --- | --- |
| 亚临界 | `p = 0.40` | 树簇全是小斑点，火烧不出去 |
| 近临界 | `p = 0.59 ≈ p_c` | 同一参数不同 seed 烧掉的可能从几十到几千 |
| 超临界 | `p = 0.75` | 几乎每次都烧穿森林 |

每个 regime 跑 60 个独立 seed，记录每次的 `static_fire_size`。

## 关键观察

运行后的典型输出：

```
sub-critical (p=0.40):  mean=  10.8   max=  43    p95=  26
near-critical (p=0.59): mean=1818.6   max=3370    p95=3244
super-critical (p=0.75):mean=4694.1   max=4834    p95=4822
```

平均火灾尺寸跨越**三个数量级**，仅仅因为密度从 0.40 涨到 0.75。中间那一档（接近 `p_c`）的方差最大——这是相变附近"巨涨落"的指纹。

## 产出图

- `phase1_post_fire_*.svg`：三种密度下点火后的森林快照（绿=树、红=火、沙黄=空地）。亚临界下火只烧掉几片孤立小簇；超临界下整片森林被烧成一大块沙黄。
- `phase1_size_per_seed.svg`：60 seed 的火灾大小折线（对数 y 轴），三色叠图。
- `phase1_mean_fire_size.svg` / `phase1_p95_fire_size.svg`：三种 regime 的均值与 P95 柱状图。

## 为什么这一阶段重要

- 给读者一个**直觉锚点**：相变不是"曲线略微陡一点"，而是数量级层面的命运分叉。
- **超临界看似"高产"** 因为树多，但单次火灾就能毁掉；**亚临界看似安全** 但木材产量很低；近临界**方差最大**——这正是相变附近"巨涨落"的标志。
- 引出阶段二的核心问题：能不能用几条统计曲线**精确地**定位 `p_c`？
