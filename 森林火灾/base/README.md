# Base 初始素材脚本详解（Case 5：森林火灾）

本目录是题目方提供给玩家的"森林防火数字孪生"脚手架。后续四个阶段都应基于这里的脚本继续开发，不要另起炉灶。

```
case5/base/
├── forest_model.py         # 共用模型：静态渗流模式 + Drossel–Schwabl SOC 模式 + 自适应疏伐
├── starter_simulation.py   # 稀疏森林单次点火基线（必须先跑）
├── plotting.py             # matplotlib 绘图与对数分箱直方图工具
└── __init__.py
```

## 1. `forest_model.py`：场景核心模型

模型是一张 `L×L` 周期边界正方网格，每个格子有三态：

| 状态 | 数值 | 含义 |
| --- | --- | --- |
| `EMPTY` | 0 | 空地 / 防火带 |
| `TREE`  | 1 | 一棵树 |
| `FIRE`  | 2 | 一棵正在燃烧的树 |

模型一份代码支持两种模式，分别对应不同阶段：

### 1.1 `mode="static"`：渗流 / 单次点火

阶段一、阶段二用这个模式。给定密度 `p` 随机长树，再在某个位置点火，火按"邻接燃烧 → 烧完变空"的规则一圈一圈扩散，直到没有正在燃烧的格子。

输出包含：
- `static_fire_size`：本次火灾烧掉的树数；
- `static_fire_duration`：火扩散持续了多少 sweep（≈ 火头从中心走到边界要几步）；
- `static_largest_cluster`：点火前最大连通树簇大小，是渗流的标准序参量。

二维方格点渗流的临界密度 `p_c ≈ 0.5928`：当 `p < p_c` 时只有零散小簇，火烧不远；当 `p > p_c` 时出现跨越整个森林的"无穷簇"，火可能烧光大片森林；恰在 `p ≈ p_c` 时簇尺寸的分布是幂律的，火灾大小没有特征尺度——这就是经典的相变 / 临界现象。

### 1.2 `mode="soc"`：Drossel–Schwabl 自组织临界

阶段三、阶段四用这个模式。每个 sweep 顺序执行：

1. **慢生长**：每个空地以概率 `p_grow` 长一棵树；
2. **（可选）疏伐**：阶段四的 `adaptive_thinning` 策略；
3. **火势扩散**：当前正在燃烧的格子点燃邻居、自己变空；
4. **稀有闪电**：每棵树以 `p_lightning` 概率被雷击点燃；
5. 记录树木密度、燃烧前线、点火数等时间序列；火灾结束时把规模、持续时间、最大前线宽度写入 `out.fires`。

当 `p_lightning << p_grow << 1`（典型如 `1e-4` vs `0.02`）时，系统会自发演化到一个稳态：
- 树木密度在某个值附近小幅震荡；
- 火灾大小分布 `P(s)` 在双对数坐标下呈幂律，指数 `τ ≈ 1.15` 左右（理论文献给出的二维 Drossel–Schwabl 模型值）；
- 火灾持续时间分布 `P(T)` 同样是幂律。

这就是"自组织临界（SOC）"：不需要外部精调密度，系统自己"长 → 烧 → 再长"地维持在临界附近。

### 1.3 `adaptive_thinning`：阶段四的反馈策略

工程上你可以这样想：林业局派出的疏伐队不可能一夜间把整个森林整治一遍，但可以**优先清理高风险热点**——那些局部树木密度过高的地方。

参数：
- `thinning_radius`：邻域半径（默认 `2`，即 5×5 窗口）；
- `thinning_threshold`：局部密度高于该值视为"高风险"（默认 `0.78`）；
- `thinning_rate`：高风险格每 sweep 被清理掉的概率（默认 `0.02`）。

阶段四要回答：
- 这种**只看本地**的简单策略，能不能把巨型火灾的尾部压低？
- 它会不会把森林清得太空，让木材产量大跌？
- 它对参数 `f / p` 的鲁棒性如何？

## 2. `starter_simulation.py`：稀疏森林基线

默认参数 `L=64, density=0.40 < p_c`。它会：

1. 画初始森林快照 `starter_initial_forest.svg`；
2. 中心点火并跑到火灭，画事后森林 `starter_post_fire.svg`；
3. 用 30 个不同 seed 重复实验，把每次火灾大小画成折线 `starter_size_per_seed.svg`。

你应当看到：火灾几乎都很小（几十到几百棵），不同 seed 之间方差不大、没有"系统级巨火"。这就是亚临界森林的"安全但低产"基线：树长得不密，所以一次雷击只烧掉一小片。

## 3. `plotting.py`：临界统计与绘图工具

封装的常用工具：

- `rolling_mean(values, window)`：滑动平均，时间序列降噪；
- `log_hist(data, bins)`：对数分箱 PDF，是看幂律的标准做法；
- `plot_lines / plot_bars / plot_forest / plot_loglog_distribution`：matplotlib 包装；
- `plot_forest`：用三色（沙黄=空地、深绿=树、亮红=火）画森林快照；
- `percentile`：算尾部分位数（例如 `P99` 火灾规模），阶段四会用。

绘图全部输出为 SVG，可在浏览器或编辑器中打开，矢量缩放不糊。
