# Phase 2：定位渗流临界点

## 目标

把阶段一的"体感对比"升级成**统计意义上的临界诊断**：通过密度扫描，找出二维方格点渗流的临界密度 `p_c ≈ 0.5928`，并验证有限尺寸效应。

## 实验设计

- 密度网格：`p ∈ {0.30, 0.32, ..., 0.80}`（步长 0.02，共 26 点）；
- 每个 `p` 跑 50 个独立 seed；
- 同时跑两种系统尺寸 `L = 48` 与 `L = 80`（有限尺寸对照）；
- 每次记录：单次火灾尺寸 `s`、点火前最大簇大小（渗流序参量原始材料）。

## 关键统计量

- **序参量** `P_∞(p) = <largest cluster> / N`：低密度 `~0`，高密度 `~1`。临界附近呈陡峭跃升，但有限系统不会真正"零变陡阶"，跃升宽度随 `L` 缩小。
- **类磁化率** `χ(p) = Var(largest cluster) / N`：对应序参量的涨落，临界处达到峰值。这是**比 `P_∞` 更灵敏**的临界指针。
- **火灾尺寸**：`<s>(p)` 与 `P99(s)(p)`，二者在 `p_c` 附近指数式跃升。

## 关键观察

典型输出：

```
[phase2] L=80 susceptibility peak at p* = 0.580
[phase2] literature p_c   = 0.5928
[phase2] |p* - p_c| (L=80) = 0.013
[phase2] L=48 susceptibility peak at p* = 0.580
```

50 seed × 26 点 × 2 尺寸的简单扫描就能把 `p_c` 定位到 ±0.02 的精度——并且 `L=80` 的 χ 峰比 `L=48` 更陡更高，符合有限尺寸标度的预期。

## 产出图

- `phase2_order_parameter.svg`：`P_∞(p)` 的两尺寸对比，标注 `p_c=0.5928` 参考线。
- `phase2_susceptibility.svg`：`χ(p)` 的两尺寸对比。`L=80` 的峰更高更尖。
- `phase2_fire_size.svg`：`<s>` 与 `P99(s)` 的对数 y 轴扫描，临界附近呈跃升。

## 为什么这一阶段重要

- 把"看起来在变"变成**可证伪**的相变诊断：χ 峰位置、峰高度随 `L` 的标度都是文献明确预测的。
- 引出阶段三的反差：**这里需要扫描参数才能看到临界**。但下一阶段会发现，加入慢生长 + 闪电的动力学后，**系统会自己跑到临界附近**——这就是 SOC。
