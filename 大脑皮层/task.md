# Case 3 · 皮层雪崩之谜：自组织临界的“神经回响”

> *“大脑可能正悬停在一种叫做‘自组织临界’的特殊态附近。在那里，
> 微小的外界刺激既不会被淹没成寂静，也不会被放大成癫痫发作，而是被
> 转化成一阵阵跨越多个尺度、毫无特征长度的‘雪崩’。如果这是真的，
> 那么大脑用来处理信息的算法，就和雪堆塌方、地震断层、森林大火背
> 后的物理是同一件事。”* —— John Beggs (2008)

## 0. 故事背景

你正在一家神经技术初创公司当 AI 工程师。公司刚刚拿下了一份政府订单：
为一个**皮层数字孪生（digital cortical twin）**做物理校准。客户的实
验生物学家在大鼠初级视皮层的 **多电极阵列** 上记录到大量“神经雪崩”
（neuronal avalanches）：每隔一段时间，会有几十到几百个神经元在短短
几毫秒内连环放电，雪崩规模 ``s`` 的分布严格服从幂律 ``P(s) ∝ s^{-3/2}``，
雪崩时长 ``T`` 的分布也服从幂律 ``P(T) ∝ T^{-2}``。这正是 2003 年
Beggs & Plenz 首次报告、之后被 *Nature*、*Science* 反复确认的“皮层
临界态指纹”。

公司给你的数字孪生只是一个最简的随机图分支模型，**默认参数下完全亚
临界**：刺激随便给，活动很快归零，根本没有任何幂律。生物学家半信半
疑地把代码丢给你：“你这玩意儿要是出不了 Beggs–Plenz 的指纹，我们就
给政府交不了差。”

你接过来一看：整套代码就放在 `case3/base/` 里，一共 ~370 行 Python，
和 case1 / case2 同源。你心里盘算：

> *“这本质上和地震断层（case 2）一样——又是一个 SOC 模型。但这次
> 的‘普适类’是 mean-field 分支过程，验证目标也变了：不仅要画出
> 幂律，还得同时给出三个独立指数 ``τ``、``α``、``1/σνz``，并验证它
> 们之间的 **Sethna crackling-noise 关系** 才算合格。客户还点名要看
> 两个版本：一是手工调出来的临界态（“tuned”），二是模型自己锁定的
> 临界态（“self-organized”）。”*

按下回车键之前，你估计这事至少得花你**半天**。

## 1. 起始素材（题目方提供）

```
case3/base/
├── neural_model.py         # 共用模型（256 神经元 × 度 8 随机有向图）
├── starter_simulation.py   # 亚临界基线（必须先跑）
├── plotting.py             # 绘图 + 指数估计 + shape collapse 工具
└── README.md               # 上面三个脚本的逐段中文解读
```

模型核心规则（精简版）：

1. 每个宏观仿真步随机选一个神经元注入 ``drive_kick`` 外部输入；若该
   神经元跨过阈值 ``θ=1``，触发主尖峰。
2. 主尖峰与所有后代构成一场“雪崩”。每代为同步、离散时间，传播规
   则：发放神经元 ``i`` 给每个下游 ``j`` 递送 ``J · u_ij``，``j`` 跨
   阈则进入下一代。
3. 标称分支比 ``σ = k · J``。临界点 ``J_c = 1/k = 0.125``。
4. 阶段二可选打开**动力学突触**：每次发放
   ``u_ij ← u_ij · (1 - ε)``，每个宏观步全网突触按
   ``u ← u + (1 - u)/τ_rec`` 恢复。这是 Tsodyks–Markram 机制。

> 详细模型与所有调参旋钮见 `case3/base/README.md`。

跑 starter：

```bash
python case3/base/starter_simulation.py
```

会得到 3 张 SVG 在 `case3/figures/starter_*.svg`。一眼能看到：分布快
速衰减，最大雪崩规模 ~15 ——典型的亚临界态。

## 2. 阶段一 · 调参临界 (Tuned Criticality)

> 难度 ★★★☆☆ —— 单参数搜索，但验证关 5 项联动。

**任务**：在 base 模型基础上写一份新脚本（建议放
`case3/solution/phase1_solution.py`），不修改模型机制，只调
``J``。要求：

1. **定位** ``J_c``：扫 ``J ∈ [0.06, 0.135]``，画出平均雪崩规模
   ``⟨s⟩(J)``，识别跳变点（应在 ``J = 1/k = 0.125`` 附近）。
2. **临界规模 PDF / CCDF**：在临界 ``J``、亚临界、超临界各跑一组
   长仿真，画三段对比的 ``s`` 与 ``T`` 的双对数 CCDF；对临界段用 Hill
   / Clauset 估计指数：
   - ``τ ≈ 1.5``  （Beggs–Plenz mean-field）
   - ``α ≈ 2``    （branching-process）
3. **⟨s|T⟩ 标度**：在临界 ``J``，把雪崩按时长分桶并画
   ``⟨s|T⟩(T)`` 的双对数图，拟合斜率得到 ``1/(σνz) ≈ 2``。
4. **Sethna crackling-noise 关系**：检验
   ```
   (τ - 1) · σνz  =  α - 1
   ```
   你测出来的三个指数必须能让上式两边相对误差 **≤ 10 %**。这是阶段一
   的真命题。

合格标准（满足任意 4 项视为通过，5 项全过为满分）：

- [ ] ``⟨s⟩(J)`` 单调上升并在 ``J ≈ 0.125`` 附近显著陡升
- [ ] 临界 ``τ ∈ [1.40, 1.60]``
- [ ] 临界 ``α ∈ [1.60, 2.10]``（有限 N 让 α 偏低很正常）
- [ ] ``1/(σνz) ∈ [1.50, 2.20]``
- [ ] crackling 关系相对误差 ≤ 10 %

参考实现：见 `case3/solution/phase1_solution.{py,md}` 与
`case3/figures/phase1_*.svg`。

## 3. 阶段二 · 自组织临界 (Self-Organized Criticality)

> 难度 ★★★★★ —— 你必须让系统**不靠手调**就跑到临界态。

**任务**：写 `case3/solution/phase2_solution.py`，开启
``dynamical_synapses=True``，并选 ``J0`` 与 ``ε``、``τ_rec``，让模型
**从任何超临界初值出发都自动收敛到** ``σ_eff ≈ 1``。要求：

1. **稳态存在**：画 ``σ_eff(t)`` 与 ``⟨u⟩(t)`` 双轴，长时间稳态在
   ``σ_eff = 1`` 附近 ±10 % 内波动。
2. **多尺度雪崩**：自组织态的 ``P(s)``、``P(T)``、``⟨s|T⟩`` 都能拟
   合出明确的幂律段。
3. **鲁棒性**：跑至少 **3 组** ``(J0, seed)`` 组合（建议
   ``J0 ∈ {0.16, 0.20, 0.30}``），所有组合 late-time
   ``⟨σ_eff⟩`` 都落在 ``1.00 ± 0.10`` 内。
4. **Sethna 关系仍成立**：自组织态下三指数也必须满足
   ``(τ - 1) · σνz ≈ α - 1``，相对误差 ≤ 10 %。
5. **形状塌缩**：选若干时长桶 ``T``，画其平均剖面；再按
   ``T^{1 - 1/σνz}`` 重标，**几条曲线塌缩成一条** = 普适标度函数存
   在 = 临界态铁证。

> **物理常识**：突触耗竭机制只能从超临界把系统拉**下来**到临界；
> 严格亚临界初值会一直亚临界（不发放就不耗竭）。题目因此要求所有
> ``J0 ≥ J_c``。这是 Levina–Herrmann–Geisel 2007 (*Nat. Phys.*) 的
> 经典结果。

合格标准（满足任意 4 项视为通过，5 项全过为满分）：

- [ ] σ_eff 与 ⟨u⟩ 都达到稳态
- [ ] 3 组初值收敛 ⟨σ_eff⟩ ∈ [0.90, 1.10]
- [ ] τ、α、1/σνz 三指数都能从自组织态实测得到
- [ ] crackling 标度关系误差 ≤ 10 %
- [ ] 形状塌缩可视化成功

参考实现：`case3/solution/phase2_solution.{py,md}` 与
`case3/figures/phase2_*.svg`。

## 5. 进阶玩法（不计入评分但极好玩）

完成上面 8 张图之后，下面这些“支线任务”任选一两个写在
`solution/extras/` 即可，可让你的解答从 “合格” 上升到“惊艳”：

1. **网络拓扑实验**：把随机正则图换成 **小世界图**或 **scale-free**
   入度分布，临界点位置 ``J_c`` 是否还落在 ``1/⟨k⟩``？普适指数 ``τ``
   是否从 1.5 偏向 ``log(N)`` 修正过的值？
2. **抑制性神经元**：把 20 % 的神经元变成抑制性（``J<0``）。系统从
   有兴奋-抑制平衡的角度还能 SOC 吗？σ_eff 的稳态值是否被改写？
3. **响应函数与动态范围**：在已自组织的系统上加恒定外部强度
   ``r``，画 ``⟨s⟩(r)``。Kinouchi–Copelli 2006 (*Nat. Phys.*) 预言
   临界态拥有最大动态范围；你能复现这条曲线吗？
4. **空间传染**：把神经元嵌入二维网格，下游邻居只连最近邻；这就把模
   型从 mean-field 换到了 2-D 定向渗透 (DP)。``τ`` 应当从 1.5 变成 ~
   1.10（2-D DP 类）。试试。
5. **批判性失败**：故意把 ``ε`` 设到 0.5、``τ_rec`` 设到 50，让突触
   恢复**比驱动还快**——此时 SOC 应该消失。给出失败的 σ_eff(t) 与
   PDF。
6. **贝叶斯指数估计**：把 Hill 估计换成 Clauset–Shalizi–Newman 似然
   比检验，给出每个普适指数的 95 % 置信区间。
