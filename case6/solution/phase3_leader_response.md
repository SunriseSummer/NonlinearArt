# Phase 3：临界响应——领飞与阵风

## 目标

阶段二定位了相变位置，本阶段验证它的**工程含义**：在三种 `eta` 下，集群对外部信号的响应能力到底差多少？

## 实验一：领飞无人机

把粒子 `0` 钉成"领飞"无人机，朝向永远是 `pi/2`（北）。所有其他粒子按正常 Vicsek 规则演化。计算

```
A(t) = (1/N) Σ cos(theta_i(t) - theta_leader)
```

随时间的演化。`A=1` 表示集群完全和领飞者同向。

典型输出：

```
[phase3] sub-critical (eta=1.5):    final alignment = 0.882
[phase3] near-critical (eta=3.5):   final alignment = -0.128
[phase3] super-critical (eta=4.5):  final alignment = 0.006
```

解读：

- **低噪声**：集群锁成一坨，且领飞者连续 700 步往北推，**最终把整坨拽到了北方**，对齐 0.88。代价是：起初集群可能锁向其它方向，要花几百步才被领飞者拽过去。
- **近临界**：朝向涨落巨大，单个领飞者（1 / 400 = 0.25%）的影响被噪声淹没，集群随机锁在某个非"北"方向，对齐反而成了 -0.13。
- **高噪声**：根本没有锁向，对齐永远 ≈ 0。

> 这个结果和 Vicsek 教科书"临界放大最敏感"似乎冲突？其实并不：教科书指的是**对小信号的瞬时响应斜率**最大；这里测的是**单个固定领飞者长期能拉动的对齐**——低噪声下集群已经同向、被领飞者持续拉动可以慢慢形成共识；近临界下噪声会一直把集群"打散"。这正是工程师真正关心的 trade-off：**响应大不等于稳定跟随**。

## 实验二：阵风脉冲

让所有粒子在 `t ∈ [300, 340]` 同时被加上 `delta_theta = 0.25` rad 的角度偏移，模拟突发气流。看 `phi(t)` 的扭曲幅度与恢复速度。

- 低噪声下：阵风把集群整体掰个 0.25 rad，`phi` 瞬时下降一点点，结束后立即回弹（因为锁向能力强）；
- 近临界下：`phi` 的扭曲幅度最大、恢复时间最长（**临界慢化**经典签名）；
- 高噪声下：`phi` 本来就很低，阵风没什么可"扰动"的。

## 为什么这一阶段重要

- 把"临界放大"从抽象数学变成**可以工程量化的指令传输**问题；
- 揭示一个微妙事实：**最大稳态对齐**（低噪声）与**最大瞬时易感性**（近临界）不是同一回事；
- 直接为阶段四提供动机：固定 `eta` 永远在和环境扭打，只有反馈控制器能根据需求**实时**把集群推到合适位置。
