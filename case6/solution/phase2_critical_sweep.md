# Phase 2：定位有序–无序相变

## 目标

把阶段一的"体感"升级成可重复的统计诊断：通过 `eta` 扫描，定位 Vicsek 集群在固定密度 `rho=4` 下的临界噪声 `eta_c`。同时验证有限尺寸效应。

## 实验设计

- 噪声网格 `eta ∈ {0.5, 0.75, ..., 5.5}`（21 点）；
- 两个系统尺寸 `N=200` 与 `N=800`，**保持密度** `rho = N/L²` 不变（box_size 自动调整）；
- 每个组合跑 900 步 / warmup 300 步，记录 warmup 后 `phi(t)` 的尾部样本。

## 关键统计量

- **序参量** `<phi>(eta)`：从低噪声的 ~1 单调下降至高噪声的 ~0；
- **易感性** `chi = N · Var(phi)`：临界处取峰；
- **Binder 累积量** `U_4 = 1 - <phi^4>/(3 <phi^2>²)`：不同 N 的曲线在 `eta_c` 附近交叉。

## 关键观察

典型输出：

```
[phase2] N=200 chi peak at eta* = 4.000
[phase2] N=800 chi peak at eta* = 3.500
[phase2] density = 4.00
```

- 易感性峰位置在 `eta ≈ 3.5–4.0`，跨密度文献给的 Vicsek 临界 `eta_c(rho=4)` 与此量级一致；
- **峰位随 N 减小**——这是 Vicsek 模型已知的有限尺寸 / 隐藏一阶分量效应；
- **峰值随 N 增大**：`N=800` 的 `chi` 峰显著高于 `N=200`，说明背后是真正的临界涨落而非测量噪声。

## 为什么这一阶段重要

- 把"相变位置"变成可证伪的数字：`eta_c` 大致 3.5–4.0；
- 引出阶段三的关键反差：相变附近**最敏感**——但 Vicsek 模型经常被引用为"教科书级临界放大例子"。下一阶段我们用领飞节点和阵风脉冲来直接验证临界附近是否真的"灵敏"。
