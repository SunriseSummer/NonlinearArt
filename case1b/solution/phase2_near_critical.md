# 阶段二参考实现详解（`phase2_near_critical.py`）

## 1. 阶段目标回顾

阶段二让玩家把网络从"远离临界"逐步推到"接近临界"。
故事上：早高峰强度持续上升，调度员维持原有的 `spill_prob` 路由策略不
动，单纯让 `inflow_rate` 变大，观察网络自身从安静到开始振荡的全过程。

需要展示的核心现象：

1. 平均负载随 demand 上升，但很快趋于饱和；
2. 拥堵传播范围与平均级联规模随 demand **非线性增长**；
3. 存在一个 "**stress edge**"——在它附近，再加一点车就会让网络明显
   敏感起来；
4. 三段（亚 / 临界 / 超）的时间序列直观差别非常大。

## 2. 核心流程

脚本固定 `spill_prob=0.30, dissipation=0.18`，扫描

```python
inflows = [0.4, 0.6, ..., 2.4]
seeds   = [2026, 17, 991]
```

对每个 inflow 在 3 个种子下跑 4500 步、丢掉前 800 步，再取均值。
检测 stress edge 的判据是：

> 第一个使 `<congestion_range> >= 0.25` 的 inflow。

`0.25` 这个阈值是经验选取，对应"平均每 4 步就有一次拥堵高位"，刚好是
拥堵开始可见、还没有彻底失控的拐点；它把扫描划成了三段，便于进入下一
步的"三段对比"。

## 3. 实测结果（可复现）

```
inflow   <load>   <thrpt>   <cong_range>   <s>
0.40     2.127    0.105       0.033     1.14
0.60     2.384    0.247       0.080     1.13
0.80     2.466    0.380       0.117     1.17
1.00     2.515    0.516       0.159     1.19
1.20     2.539    0.642       0.194     1.22
1.40     2.534    0.761       0.233     1.23
1.60     2.550    0.877       0.268     1.26  <-- stress edge
1.80     2.541    0.989       0.299     1.28
2.00     2.517    1.093       0.337     1.28
2.20     2.530    1.208       0.368     1.32
2.40     2.532    1.328       0.405     1.35
```

读图要点：

- 平均负载早早到 ~2.5 就饱和了——这是"系统能在多忙的时候保持有序"
  的边界；之后加车主要靠**更频繁的级联**来排出。
- `<cong_range>` 与 `<s>` 都在缓慢上升，但越靠后越敏感。stress edge
  之后，每加 0.2 demand 都能直接看到拥堵传播范围抬升一个台阶。

## 4. 三段对比

按 stress edge ± 0.6 选 sub / near / super 三个 inflow（在边界处会
clamp 到扫描范围内），每段跑 6000 步：

- `phase2_demand_sweep.svg`：双 y 轴展示 `<load>` 与 `<thrpt>` 随
  inflow 的曲线，标出 stress edge 的虚线参考。
- `phase2_regime_compare.svg`：三段的负载（实线）与吞吐量（虚线）时
  间序列叠图，肉眼能看出超临界段抖动最大。
- `phase2_avalanche_dist.svg`：三段的级联规模分布（双对数坐标）——
  接近 stress edge 的曲线最长尾，正是临界的标志。

## 5. 与 case1 phase1 的差异

case1 phase1 扫描的是 `spill_prob`，并以 `var(s)/<s>` 易感度峰值定临界点。
本阶段改用 demand 作为主变量，更贴近"早高峰"叙事，同时换用拥堵传播范围
作为判据——它对调度员而言更直观、可操作。两套思路是互补的。

## 6. 临界态诊断（`run_phase2_criticality_diagnostics`）

> ⚠️ **针对 PR 评审 #4328219231**：上面三张"运营图"讲清了"亚 / 临界 /
> 超"的故事，但**它们本身还不能证明系统真的处于临界**。强耗散区间
> 下的级联规模太小（max ≈ 8），距离临界系统该有的多个数量级幂律分布
> 还差很远。  
> 因此本脚本**额外**跑一遍模型，把它切到 BTW 友好的参数（`threshold=4`,
> `dissipation=0.05`，`spill_prob` 当作控制参数扫描），输出三张诊断图，
> 系统地证明这就是一个临界系统。

### 6.1 易感度峰值（`phase2_susceptibility.svg`）

扫描 `spill_prob ∈ [0.50, 1.00]`，每个 `p` 上跑 3 个种子、共 ~7000 步，
合并所有非平凡级联，计算：

- `<s>`：平均级联规模；
- `χ = var(s) / <s>`：易感度（second-moment / first-moment）。

**实测结果**（可复现）：

```
p     <s>      χ=var/<s>   max_s
0.50  1.73     0.879        13
0.60  2.04     1.321        20
0.70  2.47     1.955        23
0.80  3.17     3.079        30
0.90  4.66     6.316        57
0.95  6.20     9.045        68
1.00  9.86    18.501       132
```

`χ` 单调上升并在 `p_c = 1.00` 处取得最大值——这是相变中"易感度发散"
的典型信号。图中以红色虚线标出 `p_c`，蓝绿曲线分别是 `<s>` 和 `χ`，
**双轴**便于看清两者的相对走势。

### 6.2 临界点处的幂律拟合（`phase2_powerlaw_fit.svg`）

把 `p_c` 处的级联规模 `s` 与持续时间 `T` 各自做对数分箱直方图，对中段
（去掉首尾偏置）做最小二乘拟合：

- `P(s) ∝ s^(-τ)` ⇒ **τ ≈ 1.83，R² ≈ 0.946**
- `P(T) ∝ T^(-α)` ⇒ **α ≈ 2.26，R² ≈ 0.939**

这两个指数都在 BTW 类沙堆模型的文献区间内，R² > 0.94 表明在两个数量级
范围里**对数线性关系非常稳定**。这是"系统处于临界"最直接的可视化证
据——临界系统才会在多个尺度上都呈现同一个无标度 (scale-free) 分布。

### 6.3 有限尺度标度（`phase2_finite_size_scaling.svg`）

在 `p_c` 上对 `L ∈ {16, 24, 32}` 重复实验：

```
L     N      <s>       max_s
16   5975   8.65      122
24   6216   9.86      132
32   5994   9.81      175
```

三条分布在双对数下**主体重合**（同一幂律），但**截断 (cutoff) 随 L 增加
而向右移动**。这是 finite-size scaling 的标志性现象：分布的尾部被有
限网格截断，扩大网格→截断变远，证明那条幂律不是 20×20 偶然产物。
反过来，如果尾部不随 L 改变，说明你看到的不是临界，而是某种内禀
长度尺度——这正是 case1b 之前的强耗散版本会失败的地方。

### 6.4 综合判据

把三张诊断图合在一起读：

| 现象 | 诊断量 | 实测 | 含义 |
| --- | --- | --- | --- |
| 易感度发散 | `χ(p)` 峰值 | `p_c=1.00, χ≈18.5` | 控制参数扫描指出相变点 |
| 无标度分布 | `τ, α, R²` | `τ=1.83, α=2.26, R²>0.94` | 临界点上是真正的幂律 |
| 截断与系统尺寸标度 | `max_s` vs `L` | `122 → 132 → 175` | 不是有限尺寸假象 |

只有这三条同时满足，才能下结论"系统处于临界态"。
